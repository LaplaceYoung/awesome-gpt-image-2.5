# GPT Image showcase sources

A lightweight archive of public GPT Image showcase collections discovered through Ego Lite web search. Original wording and images remain with their authors; this index records provenance and points to the source pages.

## Public prompt collections

- [Pixmind-io/awesome-gpt-image-2-prompts](https://github.com/Pixmind-io/awesome-gpt-image-2-prompts) — 150+ GPT Image 2 prompts with locally hosted example images, organized by cinematic portraits, product photography, UI/UX, posters, text rendering, and more. We use it as a prompt lineage reference and adapt wording for GPT Image 2.5.
- [EvoLink GPT Image 2 Prompts](https://evolink.ai/gpt-image-2-prompts) — curated prompt cards covering portraits, posters, UI mockups, product shots, and character design. Use the page for the original prompt text and preview context.
- [freestylefly/awesome-gpt-image-2](https://github.com/freestylefly/awesome-gpt-image-2) — compact case-gallery format and prompt templates that inspired this repository's traceable case layout.

## Adaptation policy

When a source publishes prompt text, preserve the source URL and attribution, then place the original wording in a case's **Source prompt** block before any GPT Image 2.5 adaptation. When a source only publishes an image, label the result as **reverse engineered** and describe visible composition, typography, camera, lighting, materials, and constraints rather than presenting the reconstruction as the author's original prompt.
